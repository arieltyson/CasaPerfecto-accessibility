# CasaPerfecto Accessibility Standards & Tracking

Welcome to the public accessibility repository for `CasaPerfecto`. Everyone looking for a home should be able to use it, regardless of ability.

- Read the statement: [arieltyson.github.io/CasaPerfecto-accessibility](https://arieltyson.github.io/CasaPerfecto-accessibility/)
- The site: [arieltyson.github.io/CasaPerfecto](https://arieltyson.github.io/CasaPerfecto/)

## Why is this on GitHub?

Accessibility is ongoing work, not a one-time checklist. This repository is our public record of:

1. **Compliance Tracking:** Our conformance with WCAG 2.2 Level AA.
2. **Known Limitations:** Gaps we know about, listed in `KNOWN_ISSUES.md`, so you know what to expect.
3. **Community Feedback:** A direct line for people who use assistive technology to request fixes.

## Reporting an Accessibility Barrier

If you run into a barrier while using `CasaPerfecto` (for example an unlabeled control, low contrast, or motion that cannot be turned off):

1. Open a new **Issue** in this repository.
2. Describe the barrier, the assistive technology you use (such as VoiceOver, NVDA or Voice Control), and your browser and device.
3. Accessibility issues are fixed before new features.
